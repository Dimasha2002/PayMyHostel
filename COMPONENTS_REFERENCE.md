# 📚 PayMyHostel Components Reference Guide\n\n## 🏠 Pages (5)\n\n### 1. Home Page (`Home.jsx` + `Home.css`)\n**Purpose**: Landing page showcasing the hostel management platform\n\n**Features**:\n- ✅ Responsive navbar with logo and navigation links\n- ✅ Hero section with hostel room image\n- ✅ CTA button \"Get Started\" → directs to registration\n- ✅ About section with brief description\n- ✅ 6 Feature cards (WiFi, Security, Food, Library, Gym, Support)\n- ✅ Contact information section (3 contact methods)\n- ✅ 7 Hostel rules displayed in numbered list\n- ✅ Footer with copyright info\n\n**Props**:\n- `onGetStarted`: Callback when \"Get Started\" button clicked\n\n**Data**: Sample features, rules, and hostel info\n\n---\n\n### 2. Register Page (`Register.jsx` + `Register.css`)\n**Purpose**: New user registration with form validation\n\n**Features**:\n- ✅ Form fields:\n  - Full Name (text input)\n  - Email (email input with format validation)\n  - Student ID (unique identifier)\n  - Phone Number (numeric)\n  - Hostel Block (dropdown select)\n  - Room Number (numeric)\n  - Password (password input)\n  - Confirm Password (password validation)\n- ✅ Real-time error display\n- ✅ Form validation before submission\n- ✅ Prevents duplicate email registration\n- ✅ Stores user to localStorage `users` array\n- ✅ Link to switch to Login page\n- ✅ Back to Home button\n\n**Props**:\n- `onBackHome`: Navigate to home\n- `onSwitchToLogin`: Switch to login form\n\n**Validation Rules**:\n- Email must be valid format\n- Password minimum 6 characters\n- All fields required\n- Passwords must match\n\n---\n\n### 3. Login Page (`Login.jsx` + `Login.css`)\n**Purpose**: User authentication and session management\n\n**Features**:\n- ✅ Split-screen modern design\n- ✅ Login form (left side):\n  - Email input\n  - Password input\n  - \"Remember me\" checkbox\n  - \"Forgot password?\" link\n- ✅ Decorative blue panel (right side) with features list\n- ✅ Form validation\n- ✅ Credentials verified against localStorage\n- ✅ Successful login shows alert and redirects\n- ✅ Link to switch to Register page\n- ✅ Back to Home button\n- ✅ Error message for invalid credentials\n\n**Props**:\n- `onBackHome`: Navigate to home\n- `onSwitchToRegister`: Switch to register form\n- `onLoginSuccess`: Called with user object on successful login\n\n**Validation**: Email format, password required\n\n---\n\n### 4. Dashboard Page (`Dashboard.jsx` + `Dashboard.css`)\n**Purpose**: Main student dashboard with all payment and room information\n\n**Layout**:\n- **Sidebar** (250px fixed)\n  - User avatar with initials\n  - Student name\n  - Student ID\n  - Logout button\n- **Main Content Area**\n  - Topbar with student name\n  - Quick Actions grid\n  - Overview section\n  - Recent Activity feed\n\n**Features**:\n- ✅ Quick Actions (5 cards):\n  1. Pay Now (💳) - Opens PaymentModal\n  2. Payment History (📊) - Shows PaymentHistory component\n  3. Room Details (🏠) - Shows RoomDetails component\n  4. Download Receipt (📄) - Opens ReceiptModal\n  5. Hostel Notices (📢) - Shows HostelNotices component\n\n- ✅ Overview Section (4 cards):\n  - Total Due: Rs. 15,000\n  - Paid Amount: Rs. 25,000\n  - Next Payment: Jan 1, 2025\n  - Status: Active\n\n- ✅ Recent Activity:\n  - Transaction list\n  - Date, amount, status\n  - 3 sample transactions\n\n**Props**:\n- `currentUser`: User object with student info\n- `onLogout`: Callback for logout button\n\n**State**:\n- `activeSection`: Current displayed section\n- `showPaymentModal`: Show/hide payment modal\n- `showReceiptModal`: Show/hide receipt modal\n\n**Sub-components**: PaymentModal, PaymentHistory, RoomDetails, ReceiptModal, HostelNotices\n\n---\n\n## 🎯 Dashboard Sub-Components (5)\n\n### 5. Payment Modal (`PaymentModal.jsx` + `PaymentModal.css`)\n**Purpose**: Process payments for hostel fees\n\n**Features**:\n- ✅ Amount input (currency prefix: Rs.)\n- ✅ Payment method dropdown:\n  - Credit/Debit Card\n  - Bank Transfer\n  - UPI\n  - Wallet\n- ✅ Description textarea\n- ✅ Auto-calculated 2% processing fee\n- ✅ Payment summary display\n- ✅ Form validation\n- ✅ Cancel and Pay buttons\n- ✅ Modal overlay with close button\n\n**Props**:\n- `onClose`: Close modal callback\n- `onSuccess`: Called after successful payment\n\n**Processing**: 2-second simulated delay for payment processing\n\n---\n\n### 6.
